# Crystal Diffusion v1 — 周期图 + 消息传递 GNN

本仓库三个版本里的第 1 版（基线）。在**单个晶体结构**（`Ba2PrCu3O7`，13 个原子）上训练一个扩散模型，
让它能从纯噪声生成回该结构。这是「无中生有生成一个具体晶体」的最小完整流程。

## 结构表示

| 部分 | 表示 | 形状 | 扩散方式 |
|---|---|---|---|
| 原子种类 | one-hot 类别向量 | (N, K) | 当连续量加高斯噪声，采样后取 argmax |
| 坐标 | 分数坐标（周期性） | (N, 3) | 连续高斯扩散 |
| 晶格 | 3×3 矩阵（每行一个晶格向量，埃） | (3, 3) | 连续高斯扩散 |

晶格整体除以 `LATTICE_SCALE=10` 压到 O(1)，让三部分共用同一条噪声调度。

## 模型与扩散

- **骨干**：消息传递 GNN。节点特征 = one-hot 物种 + 坐标 + 晶格 + 时间嵌入 + 槽位嵌入；
  边特征 = 周期**最小镜像**距离的高斯 RBF；消息用 `sum` 聚合。
- **噪声调度**：余弦调度，默认 T=200（复用 `alpha_bar_t`）。
- **训练目标**：ε-prediction，物种 / 坐标 / 晶格三部分联合 MSE。
- **采样**：DDPM 反向，用解析后验均值与方差。

## ⚠️ 坐标误差必须用最小镜像计算

分数坐标里 **0 和 1 是同一个位置**。如果用朴素的 `|gen - target|`，
「生成 0.995、目标 0.0」会被算成差了 0.995 —— 明明是同一个点，却记成巨大误差。

本仓库所有版本的坐标误差一律用最小镜像：

```
diff = gen - target;  diff = diff - round(diff);  MAE = |diff|
```

折算成卡氏距离就是真实空间偏差（单位埃）。这是这个任务里最容易踩的评估坑。

## 目录结构

| 路径 | 职责 |
|---|---|
| `data/Ba2PrCu3O7.json` | 输入结构 |
| `src/data/structure.py` | 结构读写 + 张量转换 |
| `src/data/graph.py` | 周期最小镜像近邻 → RBF 边特征 |
| `src/diffusion/schedule.py` | 余弦调度 |
| `src/diffusion/forward.py` | 前向加噪 + 训练损失 |
| `src/diffusion/reverse.py` | DDPM 反向采样 |
| `src/models/mpnn.py` | 消息传递 GNN 去噪器 |
| `src/utils/poscar.py` | 写 VASP POSCAR |
| `scripts/train.py` | 训练 + 采样 + 导出 + 误差报告 |
| `tests/test_smoke.py` | 快速自检 |

## 依赖与运行

只需要 `torch` 和 `numpy`。

```bash
python v1_periodic_gnn/tests/test_smoke.py
python v1_periodic_gnn/scripts/train.py --steps 4000 --samples 4
```

## 参考结果

统一协议：8 个样本、固定随机种子、坐标误差用最小镜像、CPU 训练 4000 步（模型约 9.1 万参数）。

- **物种**：逐位 13/13 匹配，组成正确 8/8
- **坐标**：卡氏误差 **0.112 埃**
- **晶格**：**0.197 埃**

## 局限

- 晶格用**绝对矩阵**表示，含对晶体没有意义的「朝向」自由度，模型得从零学朝向 → 晶格精度受限。
- 物种是「one-hot 连续松弛 + argmax」，不是真正的类别扩散。
- 节点特征带槽位嵌入，因此不满足置换对称（对单结构任务是刻意的，见 v2 的实验）。

## 后续版本

- **v2**（`v2_equivariant_gnn`）：把晶格换成旋转不变的 Gram 表示 + 相对位移消息，晶格精度大幅提升。
- **v3**（`v3_d3pm`）：原子种类改用 D3PM 离散扩散。
