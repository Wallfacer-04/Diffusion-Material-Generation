# Crystal Diffusion v2 — 旋转不变晶格 + 等变消息传递

本仓库的第 2 版，专门解决**对称性**：晶格改用旋转不变的 **Gram（度量张量）表示**，
消息传递改用**相对位移**，并把「置换对称」做成可切换的开关。
示例结构仍是 `Ba2PrCu3O7`（13 个原子），与 v1 一致，便于对比。

## 本版改了什么（相对 v1）

| | v1 | v2 |
|---|---|---|
| 晶格表示 | 原始 3×3 矩阵（含朝向） | **Gram 矩阵 6 分量（旋转不变）** |
| 边特征 | 用晶格算距离 | 用 Gram 算距离（数学等价，但只含不变量） |
| 消息 | `[h_i, h_j, rbf]` | 同上 **+ 相对位移向量场**（EGNN 风格） |
| 置换对称 | 槽位嵌入（打破） | **开关 `use_slot`**（默认打开） |

为什么 Gram 能去掉朝向：对晶格做旋转等价于右乘正交阵 `L → L·R`，而
`G = L·L^T → L·R·R^T·L^T = G` 不变。用 G 的 6 个独立分量表示晶格，
模型就天然对旋转不变，不需要任何等变层。

## 已验证的对称性

`tests/test_symmetry.py`，六项全部通过：

| 检查 | 内容 |
|---|---|
| A 旋转不变 | 晶格任意旋转，Gram 表示的差异 < 1e-8 |
| B 置换等变 | `use_slot=False` 时原子重排 → 逐原子输出同步重排 |
| B2 槽位嵌入 | 默认（`use_slot=True`）会打破置换对称（刻意） |
| C 周期性 | 给坐标加整数平移，最小镜像边特征不变 |
| D 解码往返 | Gram → Cholesky 精确还原正交晶格 |
| E 基本流程 | 前向 / 一步训练 / 采样形状正确 |

## 依赖与运行

只需要 `torch` 和 `numpy`。

```bash
python v2_equivariant_gnn/tests/test_symmetry.py
python v2_equivariant_gnn/scripts/train.py --steps 4000 --samples 4
python v2_equivariant_gnn/scripts/train.py --steps 4000 --no-slot   # 复现置换等变实验
```

## 参考结果

统一协议：8 个样本、固定随机种子、坐标误差用**最小镜像**、CPU 训练 4000 步。

- **物种**：逐位 13/13，组成正确 8/8
- **坐标**：卡氏误差 **0.075 埃**
- **晶格**：**0.065 埃**

**注意**：这个预算下训练远未收敛，单次数字不适合给版本排名
（同一份代码换种子重训，晶格误差会在 0.11 ~ 0.56 埃之间摆动）。
所以这里只报告量级：v2 与 v1 都能复现该结构，坐标和晶格都在 0.1 埃量级。
设计上真正稳定的差别是：v2 的晶格表示**对旋转不变**（Gram），
丢掉了与晶体无关的朝向自由度，直接刻画键长与夹角（见上方对称性验证）。

> 顺带提醒：这个任务里坐标误差**必须用最小镜像**算。若用朴素 `|gen-target|`，
> 落在等价周期像上的坐标（生成 0.995 / 目标 0.0）会被错算成 ~1.0 的误差，
> 从而得出与实际相反的结论。

## 关键实验：置换等变在单结构任务上是负收益

关掉槽位嵌入（`--no-slot`）后模型严格置换等变，但生成的**物种组成全错**
（目标 `O7 Cu3 Ba2 Pr1`，生成 `O6 Cu4 Ba2 Pr1` / `O8 Cu2 Ba2 Pr1` 等）。

原因：本任务是「背下一个结构」，本身就依赖「哪个格位是哪个原子」，
与置换等变直接冲突。置换对称是为**学分布**（多结构训练）准备的，
用在单结构过拟合上并不划算——这是一个值得记住的结论。

## 局限

- 物种仍是 one-hot 连续松弛，不是离散扩散（见 v3）。
- 节点特征含绝对分数坐标，因此对「周期原点的整体平移」这一规范自由不满足不变性。
- 用不变量表示晶格，是「对旋转不变」而不是「对向量做等变更新」。
- 仍是单结构过拟合，不是学分布；没有条件生成。
