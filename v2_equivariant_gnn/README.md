# Crystal Diffusion v2 — 不变晶格 + 等变消息传递

本目录是仓库的第 2 版（v2），专门做**对称性**：把晶格换成旋转不变的 **Gram 表示**、
把消息传递改成用**相对位移**，并把「置换对称」做成可切换的开关，
最后用数值实验量化每一项改动的**收益与代价**。

示例结构仍是 `Ba2PrCu3O7`（13 个原子，正交晶胞），与 v1 保持一致，方便对比。

## 本版改了什么（相对本仓库 v1）

| | v1 | v2 |
|---|---|---|
| 晶格表示 | 原始 3×3 矩阵（含朝向） | **Gram 矩阵的 6 个分量（旋转不变）** |
| 边特征 | 用晶格算距离 | 用 Gram 算距离（数学等价，但只含不变量） |
| 消息 | `[h_i, h_j, rbf]` | 同上 **+ 相对位移向量场**（EGNN 风格） |
| 置换对称 | 槽位嵌入（打破对称） | **开关 `use_slot`**（默认打开） |

## 已验证的对称性

跑 `tests/test_symmetry.py`，六项全部通过（这是 v2 的核心，能自己复现，不用信口头描述）：

| 检查 | 内容 |
|---|---|
| A 旋转不变 | 晶格任意旋转 `L → L·R`，Gram 表示的差异 < 1e-8 |
| B 置换等变 | `use_slot=False` 时，原子重排 → 逐原子输出同步重排 |
| B2 槽位嵌入 | 默认（`use_slot=True`）会打破置换对称（这是刻意的） |
| C 周期性 | 给坐标加整数平移，最小镜像边特征不变 |
| D 解码往返 | Gram → Cholesky 能精确还原正交晶格 |
| E 基本流程 | 前向 / 一步训练 / 采样形状正确 |

## 依赖

只需要 `torch` 和 `numpy`，仓库根目录的 `requirements.txt` 已覆盖。

## 运行

```bash
# 对称性自检（几秒钟）
python v2_equivariant_gnn/tests/test_symmetry.py

# 训练 + 生成（CPU，默认 4000 步）
python v2_equivariant_gnn/scripts/train.py --steps 4000 --samples 4

# 复现「置换等变」实验（重建会明显变差）
python v2_equivariant_gnn/scripts/train.py --steps 4000 --no-slot
```

## 参考结果（4000 步，CPU，模型约 9.1 万参数）

- 物种：8/8 个样本全部 13/13 匹配
- 坐标 MAE：均值 **0.21**（范围 0.03–0.34，分数坐标）
- 晶格：Gram MAE **0.78 埃²**（折算成键长误差约 0.10 埃）

## 关键实验一：对称性不是免费的

用同样的「8 个样本」协议对比 v1 与 v2（同样 4000 步、同样的结构）：

| 指标 | v1（原始晶格） | v2（Gram + 槽位） |
|---|---|---|
| 物种匹配 | 13/13 ×8 | 13/13 ×8 |
| **坐标 MAE（均值）** | **0.073** | 0.211 |
| **晶格误差** | 0.197 埃 | **≈0.10 埃** |

结论：

- **旋转不变表示让晶格更准**（0.20 → 0.10 埃）：Gram 直接刻画度量（键长、夹角），
  丢掉了对晶体没有意义的「朝向」自由度。
- **代价是坐标变差**（0.073 → 0.211）：边距离改由 Gram 计算后，采样中途 Gram 可能偏离正定锥，
  距离信息退化。已排除两个假设——「每步把 Gram 投影回正定」和「关掉相对位移向量场」都只带来
  极小改善（0.221 / 0.196）——根因尚未定位，留给 v3。

## 关键实验二：置换等变在单结构任务上是负收益

关掉槽位嵌入（`use_slot=False`）后模型严格置换等变，但生成的**物种组成都对不上**：

| 样本 | 物种组成 |
|---|---|
| 目标 | O7 Cu3 Ba2 Pr1 |
| 生成 | O6 Cu4 Ba2 Pr1 / O8 Cu2 Ba2 Pr1 / O6 Cu3 Pr2 Ba2 / O8 Cu3 Ba1 Pr1 |

坐标 MAE 也退化到 0.32–0.44。

原因：本任务是「背下一个结构」，本身就依赖「哪个格位是哪个原子」，
与置换等变直接冲突。置换对称是为**学分布**（多结构训练）准备的，
用在单结构过拟合上并不划算——这是一个值得记住的结论。

## 适用范围与局限

- 物种仍是 one-hot 连续松弛，不是离散扩散（D3PM）。
- 节点特征含绝对分数坐标，因此对「周期原点的整体平移」这一规范自由不满足不变性。
- 晶格用不变量表示，是「对旋转不变」而不是「对向量做等变更新」。
- 仍是单结构过拟合，不是学分布；没有条件生成。
